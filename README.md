# Arsal Steel Traders website

Next.js (JavaScript, App Router) with Tailwind CSS.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Where things are

- `app/page.js` is the Home page, `app/about/page.js` is About Us, `app/contact/page.js` is Contact Us.
- `app/layout.js` sets the fonts (Archivo Narrow for headings, IBM Plex Sans for text) and page titles.
- `app/globals.css` holds the color palette (navy, steel grey, brass). Change colors here.
- `lib/site.js` holds the business details. Replace the TODO items with real details.

## Status

Foundation only. Page sections are added one at a time.
